# Forex Signal Platform (FSP)

Forex · ABD hisseleri · BIST · emtia · endeksler için çoklu gösterge + hacim + rejim + AI bağlamıyla **AL/SAT sinyalleri** üreten, sinyalleri **farklı seslerle sözlü olarak anlık** okuyan, düşük gecikmeli, ultra-premium web platformu.

> ⚠️ Karar destek aracıdır; yatırım tavsiyesi değildir. Kazanç garanti edilmez — tüm metrikler şeffaf biçimde backtest/walk-forward ile ölçülür.

**Stack:** Java 25 · Spring Boot 4.1 · Spring Modulith 2.1 · Spring AI 2.0 · Thymeleaf + HTMX + SSE · PostgreSQL/TimescaleDB · Valkey · TLA+
